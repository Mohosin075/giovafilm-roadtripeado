কেন এটি আপনার জন্য সবচেয়ে সেরা?
অ্যাডমিনের বাড়তি কোনো খাটাখাটনি নেই: ড্যাশবোর্ডে প্লেস বা অফার তৈরি করার সময় অ্যাডমিনকে ২বার (English ও Spanish) লিখতে হবে না। অ্যাডমিন যেকোনো ১টি ভাষাতে (যেমন স্প্যানিশ বা ইংলিশে) লিখলেই হবে।
স্বয়ংক্রিয় অনুবাদ: ব্যাকএন্ড ডাটাবেজে সেভ হওয়ার সময় Google/DeepL Translate API দিয়ে মিসিং ভাষার অনুবাদটি অটো বানিয়ে ডাটাবেজে সেভ করে নেবে।
ইউজারদের জন্য দ্রুত ও রেডিমেড: ইউজার সাইটে ES বা EN সিলেক্ট করা মাত্রই ডাটাবেজ থেকে তৈরি করা নিখুঁত টেক্সট চলে আসবে।
এডিট করার স্বাধীনতা: অটো-অনুবাদ হওয়া টেক্সটে কোনো ভুল থাকলে অ্যাডমিন ড্যাশবোর্ড থেকে পরে ম্যানুয়ালি ঠিকও করে দিতে পারবে।
বাস্তবায়নের ৩টি সহজ ধাপ:
mermaid
flowchart TD
    A[1. User Website Frontend] -->|Add Language Toggle ES / EN| B[Static UI Text via i18n JSON]

User Website: Header-এ একটি Language Switcher (ES 🇪🇸 | EN 🇺🇸) বাটন থাকবে। Navbar/Footer ইত্যাদি static টেক্সটের জন্য i18next ব্যবহার হবে।
Backend API & DB: Mongoose Schema-তে অনূবাদযোগ্য ফিল্ডগুলো { en: String, es: String } স্ট্রাকচারে থাকবে এবং ডাটা সেভের সময় অটো-ট্রান্সলেট লাইব্রেরি কাজ করবে।
Admin Dashboard: ড্যাশবোর্ড আগের মতোই থাকবে, কোনো জটিলতা নেই।












ইউজার বা অ্যাডমিন সবসময় মাত্র ১টি ভাষাতেই ইনপুট দেবে! (২টি ভাষায় লেখার কোনো প্রয়োজন নেই)।

ইউজার/অ্যাডমিনের ওপর কোনো বাড়তি চাপ থাকবে না। ব্যাকএন্ড সম্পূর্ণ অটোমেটিকভাবে দ্বিতীয় ভাষাটি তৈরি করে সেভ করে নেবে।

🔄 এটি কিভাবে কাজ করবে? (সহজ উদাহরণ)
১. ইউজার/অ্যাডমিনের দিক থেকে (Frontend):
ধরুন, ইউজার বা অ্যাডমিন ফর্ম ফিল্ডে মাত্র ১টি টাইটেল লিখলো: "Hermosa playa en San Juan" (স্প্যানিশ ভাষায়)
ফ্রন্টএন্ড থেকে ব্যাকএন্ডে সাধারণ একটি JSON রিকোয়েস্ট যাবে:
json
{
  "title": "Hermosa playa en San Juan",
  "description": "Una playa muy bonita para visitar",
  "inputLang": "es" // অথবা ইউজারের বর্তমান সিলেক্ট করা ল্যাঙ্গুয়েজ
}
২. ব্যাকএন্ডের দায়িত্ব (Backend Logic):
ব্যাকএন্ড ডাটা রিসিভ করার পর ব্যাকগ্রাউন্ডে Google Translate API দিয়ে ১ সেকেন্ডে অন্য ভাষার টেক্সট বানিয়ে নেবে এবং ডাটাবেজে সেভ করবে:

typescript
// Backend logic before saving to DB
const inputTitle = req.body.title; // "Hermosa playa en San Juan"
const inputLang = req.body.inputLang || req.lang || 'es'; // 'es'
// অটো-অনুবাদ তৈরি (Spanish -> English)
const translatedTitle = await translate(inputTitle, { from: inputLang, to: 'en' });
// Output: "Beautiful beach in San Juan"
// ডাটাবেজে ২টা ভাষাই সেভ হয়ে যাবে:
const newPlace = await Place.create({
  title: {
    es: inputTitle,                  // "Hermosa playa en San Juan"
    en: translatedTitle.text         // "Beautiful beach in San Juan"
  }
});
